# PaymentsMotion — два варианта анимации платежа

SwiftUI-прототип для iPhone. Оба варианта находятся в одном проекте Xcode.
Это демонстрация интерфейса: реальные переводы не выполняются.

## Запуск

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте либо клонируйте его через Git.
2. Откройте `PaymentsMotion.xcodeproj` в Xcode. Проект проверен в Xcode 26.2; минимальная версия iOS — 17.0.
3. В меню **Product → Scheme** выберите вариант:
   - **PaymentsMotion** — версия 1: строка превращается в отдельную карточку, после удержания карточка улетает.
   - **PaymentsMotion-Inline** — версия 2: преобразуется сама ячейка, после подтверждения она рассыпается на точки.
4. В **Product → Destination** выберите конкретный симулятор iPhone или подключённый iPhone. `Any iOS Device` подходит только для сборки.
5. Нажмите **⌘R** (▶), затем удерживайте строку **«Мама»**.

Для запуска на физическом iPhone выберите свой аккаунт в **Signing & Capabilities → Team** у target `PaymentsMotion`. При необходимости задайте свой уникальный Bundle Identifier. Для симулятора личная команда подписи не нужна.

## Как взаимодействовать

- Удерживайте строку до заполнения зелёного кольца, затем отпустите палец.
- Раннее отпускание отменяет действие и возвращает исходную строку.
- После завершения появляется тост; **«Отменить»** восстанавливает строку.
- Приложение запоминает последний вариант, запущенный через схему Xcode, и открывает его при запуске с иконки.
- Хаптики оценивайте на физическом iPhone.

Во второй версии ячейка уменьшается до 0,95 во время заполнения кольца и возвращается к исходному размеру при готовности. Круг со стрелкой делает лёгкий баунс, точки в «Переводим...» мерцают по очереди. При отпускании готовая ячейка рассыпается, после чего блок схлопывается.

## Файлы

- `PaymentsMotion/PaymentsView.swift` — версия 1.
- `PaymentsMotion/InlinePaymentsView.swift` — версия 2.
- `PaymentsMotion/PaymentsMotionApp.swift` — выбор и сохранение версии.
- `PaymentsMotion/Assets.xcassets` — изображения интерфейса.
- `PaymentsMotionUITests/PaymentsMotionUITests.swift` — UI-тесты.

## Проверка

В Xcode выберите симулятор и выполните **Product → Test** (⌘U).
UI-тесты проверяют отмену удержания, завершение, восстановление строки и сохранение варианта при перезапуске. Визуальное ощущение анимации и хаптики следует оценить на устройстве.
